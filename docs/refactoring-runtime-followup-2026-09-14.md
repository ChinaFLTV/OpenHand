# 运行时与交互一致性重构

## 实施计划

1. 检查 Flutter、Web 与原生服务边界，建立静态分析和测试基线。
2. 修复网络读取与进程清理中的无界等待、资源归属和迟到回调问题，复用已有公共工具。
3. 检查双端共享动效与异步交互，修复影响动画连续性及全局设置一致性的缺陷。
4. 执行针对性回归、完整静态检查、Web 重建与可用平台构建，复核差异后提交。

## 基线

- 工作区干净；Flutter 静态分析通过，现有 18 项测试通过。
- 保留现有主题、公共动效入口与内置 Prompt；只删除经检查确认冗余的实现。

## 实施结果

- **响应读取**：Web 超限、取消和读取失败统一走一次取消入口；不再等待可能永不完成的底层清理。释放读取锁，保留原始错误，空响应同样尊重取消信号。超时错误构造失败时，任务仍收到同一取消原因。
- **扫描运行时**：停止前同步移交旧进程的订阅，避免迟到清理取消新订阅。外部连接只保留一个待连接客户端；替换、停止和释放都会主动关闭旧连接。启动前检查失效代次，停止后不复用旧启动任务；日志按进程身份归属，失败的外部连接尝试不会让现有进程停止输出日志。
- **动效连续性**：列表与通用展开组件保存尺寸曲线状态，修复退场中重新显示时的尺寸跳变。列表响应系统减少动态效果及 TickerMode，立即清理退场条目和计时器。
- **统一退场**：Web 普通浮层、受控浮层共用弹窗退场控制器，移除重复的状态机和定时器实现。正在退场时修改全局时长，按已经播放的时间计算剩余时间；禁用动效立即关闭，并保证完成回调只执行一次。快速重开保留内容，旧计时器不再误关新浮层。
- **路由与存储**：10 个鉴权页面复用统一包装，保留原有功能开关和页面动效；懒加载复用公共超时工具。过期导航动画不能覆盖新路由，删除针对固定常量的无意义归一化。数据库和知识库目录复用统一路径入口，存储位置不变。
- **代码清理**：移除仅捕获后重新抛出的异常分支；保留真实边界回归测试。没有新增依赖、修改内置 Prompt 或改动第三方插件源代码。

## 验证边界

本次检查覆盖共享运行时、网络、存储路径、扫描服务和双端交互的上述链路。Windows、Linux 桌面应用未在对应系统运行；Rust 测试在当前 macOS 主机执行。静态分析、测试与构建通过不代表所有业务场景或所有缺陷都已验证。

macOS 构建存在既有 WebView、文件选择器插件的系统 API 弃用警告，未导致构建失败；本次没有修改依赖缓存中的第三方源码。
