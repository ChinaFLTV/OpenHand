# 重构与检查记录

## 实际调整

| 范围 | 原有问题 | 调整结果 |
| --- | --- | --- |
| Web API | 超时依赖传输层响应取消，独立维护超时错误转换 | 复用公共有界异步执行器；统一取消、超时与清理 |
| 登录态隔离 | 请求取消与传输层迟到响应缺少明确的处理边界 | 发送前、响应头返回后和正文读取后检查取消及登录态；迟到响应释放数据流 |
| 计时控制器 | 直接调用公开控制器的 `abort()` 后计时器仍运行，取消可能被错误标为超时 | 所有取消路径由信号统一清理计时器和监听器，删除冗余转发函数 |
| 全局动效 | 相同时长重复创建状态对象；重复创建系统媒体查询对象 | 时长未变时保留状态对象，复用已订阅的媒体查询 |
| 桌面会话 | 滚动布局存在始终为真的类型判断 | 删除冗余判断，保留追底与布局行为 |
| 持续集成 | 手工列举的检查只覆盖 23 个入口中的 7 个 | 自动执行全部 `scripts/check_*.dart`；Flutter、Web 作业分别限制为 30、20 分钟 |

新增回归覆盖：发送前取消、发送前切换登录态、传输层忽略取消、超时后的迟到 401、迟到响应流释放、直接取消控制器后不再误报超时。
