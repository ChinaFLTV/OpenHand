## 已实施的调整

| 范围 | 修改及结果 |
| --- | --- |
| 图像资源 | 提取首帧解码与绘图栅格化入口，统一释放 Codec、Picture；尺寸解析只订阅首帧并释放 ImageInfo 克隆，避免持续解码动图。 |
| 截图标注 | 释放解码图、导出图与文字布局资源；卸载后到达的解码结果立即释放。损坏图片显示主题化失败卡片；导出失败保留标注并提示，不再将原图当作成功结果。防止重复导出及迟到结果关闭其他弹窗。 |
| 水印与工作流导出 | 复用图像处理入口，释放文字布局与绘图资源；修复极小图片水印字号上下限倒置。合并 PNG/JPEG 重复收尾逻辑，编码或进度回调异常时仍释放栅格图像。 |
| 工作流导入 | 拒绝不支持的数值及字符串版本，不再截断后接受；对象键必须为字符串，避免隐式转换覆盖字段。正常导出再导入保持一致。 |
| 跨平台文件名 | 工作流导出和钉钉文件保存复用现有公共清理方法；处理 Windows 保留名、点目录、尾随句点、非法字符与 UTF-8 字节上限。 |
| HTTP | 响应头超时后接管并取消忽略中止信号的迟到响应体；清理有时限，保留原始超时错误。 |
| Web 超时 | 统一浏览器与无窗口环境的定时器行为；无窗口环境不再跳过请求超时和重试间隔。清除永远不可达的非正时限分支。 |
| 原生数据库 | 在线程池外串行获取访问许可，最多容纳 256 个操作，排队最多 10 秒；调用方取消时，实际运行中的操作仍持有许可，直到真正退出。 |
| 清理与质量入口 | 删除重复 WebView 挂载常量及默认参数，修正截图取消行为的错误注释；新增图像与导入边界回归并接入 CI。 |
