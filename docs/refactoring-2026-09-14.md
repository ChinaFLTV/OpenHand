# 运行时、鉴权与交互重构记录

## 范围与原则

本次从干净工作区开始，执行全仓静态分析和架构扫描，重点审查共享异步工具、Web 鉴权与事件订阅、弹窗生命周期、HAR 产物持久化及 Rust 守护进程停机。复用现有并发、缓存、动效入口，删除重复实现，保留必要的行为回归检查。内置 Prompt 未变更。

## 实施结果

1. **公共运行时**：帧合并刷新改为主动请求下一帧，在构建前同步最新状态；组件销毁时取消回调。最新任务队列先登记当前轮次的完成信号，再启动任务，修复同步重入读取旧 `idle` 的问题。
2. **Web 鉴权**：以登录版本和请求时凭据隔离响应；旧会话的成功响应、迟到 401 及慢错误正文都不能覆盖新会话。匿名认证失败不再清除已有凭据。登录、注销触发独立元数据刷新，取消旧请求。
3. **存储与超时**：共享读取入口区分“存储不可用”和“键已删除”。写入、删除失败时以当前内存认证状态为准；跨标签页删除不会复活旧凭据，设备标识保持稳定。超时错误构造失败会正常拒绝 Promise，同步任务取消与抛错不会留下未处理的取消 Promise。
4. **事件订阅**：复用对象解析工具，校验会话标识及消息基本字段；订阅构造失败可进入现有轮询兜底，卸载后不再投递初始化错误。业务回调异常与解析错误分开处理。
5. **弹窗**：关闭前先设置重入标记；输入法组词期间的 Escape 不关闭弹窗。焦点过滤考虑隐藏祖先、禁用控件及布局可见性，嵌套弹窗乱序卸载仍能恢复原始焦点。保留现有全局弹簧动效和时长设置；组件卸载后，定时器和动画帧入口拒绝迟到调度。
6. **HAR 产物**：初始化、刷新和关闭复用已有 SingleFlight、AsyncOnce；正常关闭与失败清理共用输出流释放逻辑。草稿复用 LRU 缓存，最多保留 2000 项、总计 16 Mi 字符，超限淘汰旧草稿；导出按请求时间排序，中文请求体按 UTF-8 字节计数。
7. **原生停机**：共享停机信号主动结束 SSE；收到停机信号后最多等待现有请求 5 秒。超时保留明确错误，正常运行期间不受停机时限限制。六个平台的内置二进制及摘要同步重建。
