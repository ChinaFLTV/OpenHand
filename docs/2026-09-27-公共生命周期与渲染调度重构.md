# 公共生命周期与渲染调度重构

## 实施与范围

检查覆盖 Flutter 公共工具与界面刷新生命周期、Web 语音与富文本调度、原生服务任务管理，以及项目现有全部检查入口。改动集中在有明确重复或边界问题的位置，继续使用现有并发合并、弹窗动效和通知组件；未新增架构层或修改内置提示词。

## 调整

| 范围 | 问题与处理 |
| --- | --- |
| Qdrant、Cookie、浏览器存储、工具缓存和遥测 | 五处刷新入口复用 `OpenHandSingleFlight`，删除重复 Future 登记与清理逻辑；保留刷新期间最多追加一轮的行为，并在执行操作前登记任务，避免同步重入重复启动 |
| 浏览器存储面板 | 已排队更新时不发布旧请求结果；组件销毁后不再启动刷新 |
| 工具缓存统计 | 查询失败保留上次统计或未知状态，避免误显示为零 |
| Cookie 筛选 | 统一去除搜索文本首尾空白，修正空白判断与实际匹配不一致 |
| 周期任务 | 用标准 `Future.timeout` 替代手动计时器与完成信号竞争；保留非重入、超时取消策略和迟到异常报告 |
| 桌面富文本 | 淘汰任务时同步移除空队列，避免回调异常导致逐帧报错；淘汰回调同步入队后再次检查容量，避免突破上限 |
| 桌面与 Web 富文本 | 任务执行、取消或淘汰后释放正文回调引用，避免长期保留取消句柄时继续持有正文与组件 |
| Web 语音 | 统一计时器、识别设备和朗读资源清理；识别结束不再依赖浏览器补发事件；设备创建、启动和释放失败均能退出或继续清理 |
| Web 语音发送 | 增加独立发送超时，处理同步提交异常，隔离旧通话迟到结果；底层提交仍由现有 API 请求生命周期负责 |
| Web 语音消息查找 | 统一逆序查找最后一条非空助手消息，避免复制整个消息数组，并修复末尾空回复导致重新朗读历史内容 |
