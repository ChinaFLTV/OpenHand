# 2026-09-21 重构与验收

## 实施计划

1. 建立 Flutter、Web、原生服务的检查基线，复核现有共享抽象与调用边界。
2. 修复网络取消和资源回收边界，使用现有并发、缓存工具收敛重复状态。
3. 清理静态检查问题，检查消息渲染、弹窗进退场与交互生命周期。
4. 补充可复现缺陷的回归，执行架构检查、现有组件回归及原生检查。
5. 执行 `scripts/build_web.sh` 和当前平台发布构建，记录结果后提交。

## 基线

- 起点 `fdb2a5688`，工作区干净；Flutter 与 Web 源文件共 1040 个。
- Flutter 静态检查发现 11 处问题，涉及异步上下文使用、冗余参数和格式。
- 复用现有共享工具和设计体系，不按文件大小拆分，不凭引用计数删除动态入口或有效回归。

## 已实施

| 范围 | 调整与结果 |
| --- | --- |
| HTTP 取消 | 已取消的请求不再发送；等待响应头期间独立响应取消，即使传输忽略中止也及时返回。取消与超时统一接管迟到响应，释放底层正文。 |
| HTTP 流生命周期 | 用同步订阅转发替换异步生成器，修复订阅后立即取消时清理逻辑尚未启动的问题；保留暂停、恢复、错误及正常结束语义。 |
| 模型档案 | 统一使用小写存储键，事务内清理本次更新涉及的旧大小写别名；加载已有重复档案时选择最近更新的记录。失败批次不更新数据库或内存目录。 |
| 共享状态 | 档案初始化复用可重试异步缓存，删除未读取的重复档案 Map；网络快照刷新复用 SingleFlight，移除重复 Future 登记与清理。JSON 限制复用同一配置。 |
| 浮层性能 | 菜单、下拉框、技能选择与文件选择共用视口监听 Hook；滚动、窗口变化及视觉视口变化合并到动画帧，隐藏和卸载时取消测量并移除监听。 |
| 浮层退场 | 退场期间保留 Escape 层级并禁止重复关闭，避免菜单消失前误关父弹窗；进退场继续遵循全局动画设置。 |
| 列表重排 | 修复真实浏览器移动 DOM 节点后丢失输入焦点的问题，恢复仍存在且未退场节点的焦点、选区与选择方向，不触发额外滚动；删除条目时立即释放退场节点的焦点。 |
| 旧界面清理 | 删除已被内嵌表单替代、无产品入口的双端决策配置弹窗；删除专属样式、10 个 Dart 文案成员和 Web 四种语言中的 28 条文案。移除旧弹窗回归，保留协议、草稿、真实内嵌表单和窄屏检查。 |
| 代码一致性 | 修复全部 11 处静态检查问题；历史加载显式检查组件挂载状态，清理冗余默认参数、构造方式和流程格式。模型档案回归接入 CI。 |

未新增依赖、变更数据库结构或调整内置 Prompt。没有为机械套用设计模式增加接口层，也没有按大文件体积拆分职责。

## 验证结果

- `flutter analyze --no-pub`：无问题；887 个 Dart 文件格式检查通过。
- 17 组现有组件和业务检查共 186 项通过，另有 10 项模型元数据与持久化检查通过。
- 共享辅助、架构边界及 Web 引擎检查通过。
- 新增回归先后复现了取消仍等待响应头、立即取消未释放底层流、大小写更新生成多条档案；修复后通过，包括流暂停/恢复及失败批次数据保持检查。
- Web 类型、运行时、交互、语音及产物校验通过；提交前执行 `scripts/build_web.sh`。
- 真实浏览器：弹窗生命周期 30 项、决策卡片与交互 34 项、内嵌表单 18 项通过；覆盖菜单退场、父弹窗保护、动态修改全局动效设置、排序选区保持及动画收敛。
- Rust 工作区 66 项测试、Clippy 与格式检查通过。
- `flutter build macos --release --no-pub`：成功，生成 `build/macos/Build/Products/Release/OpenHand.app`（241.7 MB）；发布包内 195 个 Web 文件与工作区 SHA-256 一致。

## 验证边界

主机为 macOS，未进行 Windows/Linux 实机验收。仓库没有 Linux Flutter 桌面工程。本轮没有修改原生引擎，也未重新生成六平台引擎二进制。macOS 构建保留已有插件 SwiftPM 兼容性提示，没有修改用户的全局 Flutter 配置。
