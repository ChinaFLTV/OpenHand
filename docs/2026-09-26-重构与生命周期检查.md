# 重构与生命周期检查

## 实施范围

在干净的 main 工作区开展检查，按公共逻辑、业务生命周期、完整回归三个阶段实施。未创建分支或工作树，未推送远端，未修改内置提示词。

| 范围 | 问题 | 调整 |
| --- | --- | --- |
| 桌面公共动效 | 不同进退场样式切换时销毁内容状态；中途反向会切换曲线并跳变 | 统一透明度与矩阵渲染结构，保持内容状态；抵达端点后才切换方向样式，中途反向沿原曲线返回 |
| 菜单、浮层、通知、钉钉正文 | 仅为更新变换而逐帧重建过渡组件 | 由公共过渡直接监听绘制与状态变化，删除外层重复 AnimatedBuilder |
| Web 会话快照 | 采样指纹忽略历史消息、审批、节流、窗口和等长错误变化 | 复用精确的消息窗口与 JSON 比较，流式尾部优先短路，忽略纯发送时间变化 |
| 语音生命周期 | 合并取消信号缺少正常结束后的解绑入口 | 增加可释放取消作用域，统一启动、测试与音频流的监听清理；合并信号旧接口复用相同实现 |
| 子智能体工具 | 工具正常结束或失败后未结束本次超时取消信号 | finally 中完成信号，解除与父任务的合并监听 |
| 性能跟踪 | 上一轮附加的取消信号可能停止下一轮；提前结束仍留下延迟计时器 | 按任务身份隔离并解绑监听，使用可取消延迟，所有结束路径完成生命周期信号 |
| 空目录清理 | 枚举异常绕过调用方错误处理，存在重复异常处理分支 | 类型检查、枚举与删除使用同一异常出口 |
| 检查基础设施 | 多个检查重复解析真实源码依赖 | 统一源码加载与 import/export 解析，迁移九个已有入口，保留业务回归覆盖 |
| 模型目录生成 | 系统临时目录没有沿用项目格式规则，生成后全项目格式检查仍有差异 | 在项目 .dart_tool 中格式化；两个目录文件仅调整格式，不修改模型数据 |

## 回归覆盖

- 动效旧实现可复现内容 State 被销毁；修复后保留位置、透明度与状态，完整入场后仍使用指定退出样式。
- 验证所有弹窗样式快速关闭、减少动态效果、监听释放，以及像素/比例滑动在尺寸变化后的绘制与点击一致性。
- 验证 Web 快照的历史消息、同长度错误、停止按钮、审批、节流、窗口与统计趋势变化；相同数据仍复用原状态。
- 验证取消作用域的重复释放、已取消信号、异常完成信号和结束操作隔离。
- 语音在线分支通过公共流创建入口连接本地回归服务，覆盖未订阅、暂停、正常结束、失败、取消与关闭。
- 性能跟踪使用受控 CDP 通道验证旧取消信号隔离、单任务复用、失败清理和提前结束无遗留定时器。
