从干净的 `main` 工作区开始，盘点 Flutter、Web、Rust、共享工具和质量入口。保留现有功能分层及全局动效入口，优先处理可复现缺陷和高频执行路径；不按文件长度机械拆分，不因静态扫描遗漏条件导入而删除有效文件。

## 已完成的调整

| 范围 | 触发条件与调整 |
| --- | --- |
| SSE 解析 | CRLF 被网络分片拆开时会误判事件边界。提取 `BoundedSseEventBuffer`，统一聊天、Responses 和 MCP 的事件组装；支持 BOM、混合换行、多行载荷、末尾未闭合事件、超限拒绝和提前停止。 |
| 流式性能 | 移除不断拼接未完成事件的旧缓冲；分片增量写入，事件完成时才拼接，避免小分片反复复制全部历史缓冲。字段解析仅移除协议规定的一个空格，保留正文空白。 |
| Web 轮询 | 运行门闩跨启停与配置变更保留，忽略取消的旧任务真正结束前不启动下一次任务；统一浏览器和无窗口环境的执行与清理路径。 |
| Web 会话隔离 | SSE 事件校验订阅时的登录状态；旧登录态事件被丢弃并关闭连接，初始化错误统一经过回调错误处理。 |
| 动效资源 | 单向动画复用公共曲线包装；图片动画和弹窗遮罩持有并释放方向曲线，重复构建不累积状态监听。图片每帧只订阅一个父动画。 |
| 动效边界 | 透明度和尺寸使用有界动画，缩放与位移保留回弹；移除交叉淡入中重复应用的位移曲线；禁用动效时展开箭头保持正确方向。 |
| 退场取消 | 两类错误卡片使用可取消的动画完成信号，卸载后不再永久等待；退场中禁用动效时完成关闭，不回跳到进场终点。 |
| 质量入口 | 提取 Flutter 临时组件检查运行器；新增动效回归并加入 CI；扩充既有 SSE、轮询、登录隔离与会话回归。修正全量格式检查发现的一处既有格式偏差。 |
