# 模型目录核验记录

核验日期：2026-09-26。范围为内置模型规格、原始元数据、请求参数约束和模型编辑弹窗。未修改内置提示词。

## 数据口径

- OpenRouter 官方 `/api/v1/models` 快照包含 458 个在线条目，本次全部刷新；新增 49 个精确 ID，保留原有 520 个 ID，目录共 569 个条目。历史条目保留不代表仍可调用。
- 网关 ID 使用网关规格；厂商原生 ID 使用厂商文档。不同端点的上下文、输出限制、价格及支持参数不互相套用。
- 不公开的知识截止日期、思考预算、价格和默认档位保持空值；不能从输出上限推算思考预算，也不能把推荐输出长度当最大值。
- 完整 OpenRouter 条目保存在 `source_metadata`，包括阶梯价格、非词元计费、端点限制、模态、默认参数及未来新增字段。所有 458 个条目与下载快照逐项比对，序列化往返不丢字段。
- 原生分档、分时、人民币和积分价格保留原币种及计费单位，不冒充单一美元词元价格。这些资料用于查阅，当前应用的固定单价估算不计算分档或分时账单。
- 静态目录和运行时同步共用映射器，静态原始数据为常量，档案按查询解析并缓存。同步支持本地快照复现、重复 ID 校验、32 MiB 限额和请求超时。

- 摘要增加可打开的来源链接与原生规格核验日期；原始元数据首次展开时才构建 JSON 树。
