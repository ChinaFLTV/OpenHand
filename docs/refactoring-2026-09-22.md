# 2026-09-22 生命周期重构与验收

## 计划

1. 检查工作区、项目结构、既有重构记录与静态分析基线。
2. 排查网络、进程、异步队列和持久化的取消与释放边界，优先修复可复现问题。
3. 复用已有并发抽象，检查双端弹窗入口、动效与通知生命周期。
4. 执行回归、架构检查、Web 重建和当前平台发布构建，记录覆盖边界后提交。

## 基线与原则

- 起始工作区干净，Flutter 静态分析通过；lib 下共 882 个文件，其中 864 个 Dart 文件。
- 复核现有共享网络、并发、队列、原子写入、缓存与动画实现，不重复建设基础层。
- 从应用入口与检查脚本扫描 import/export/part：863 个 Dart 文件静态可达，唯一候选是条件导出的 local_file_media_io.dart，复核后保留。没有发现可据此删除的孤立 Dart 文件。
- 保留有效测试；没有证据证明无用的文件不按大小、命名或引用数删除。
- 不更改内置 Prompt，不新增依赖，不为套用设计模式引入额外接口。

## 实施

- 原生 HTTP 响应头超时后接管迟到响应体，并通过现有有界清理工具取消订阅；影响所有使用该共享入口的请求。
- CDP 关闭立即终止待响应命令，不再等待底层传输清理；同步发送失败只向调用方传播一次异常，消除孤立 Future 错误。
- CDP 连接与关闭复用 SingleFlight、AsyncOnce；应用资源注册表复用 AsyncOnce，保留逆序清理、同步重入与总时限。
- 知识库依赖刷新复用 SingleFlight，删除手工 Future 登记和身份比较，保留忙碌状态与卸载检查。
- Web 后台通知在授权返回后复核页面可见性与登录状态；页面通知在登录变更后点击只关闭通知，不再导航。
- 新增连接与关闭回归接入 CI；HTTP 和通知缺陷回归加入既有检查入口。
